# Gestión de vehículos, conductores y viajes

Trabajo Práctico N.º 3 de Programación IV (UTN FRLR). Aplicación para registrar los vehículos de una empresa de transporte, sus conductores y los viajes realizados.

- `backend/`: API REST con Express, MySQL, express-validator y autenticación con JWT y Passport.
- `frontend/`: aplicación con Vite y React.
